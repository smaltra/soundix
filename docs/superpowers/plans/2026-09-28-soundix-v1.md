# Soundix v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task in this session. Scott forbids subagents and parallel agents. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Soundix v1, a free in-browser tool that lets a developer define UI/game sound events, pick a CC0 library sound (or an own file) for each, hear them on a mock UI, and download a ZIP (files + JSON, Roblox module or web JS).

**Architecture:** All logic that does not need a browser lives in `src/core/` (pure TypeScript, tested with Vitest): set model, search and "Suggested", transliteration, share link, `soundix.json`, export plan and generated texts. Browser adapters wrap it: Web Audio (`src/audio/`), localStorage and IndexedDB (`src/storage/`), fetch + JSZip (`src/adapters/`). React UI (`src/ui/`) keeps state in `useReducer` + context. `scripts/build-library.mjs` (Node + ffmpeg) turns `packs/` into `public/library/`.

**Tech Stack:** Vite, React, TypeScript (strict), Vitest, jszip, idb-keyval, lz-string, Node 22+, ffmpeg/ffprobe.

**Contract:** `docs/superpowers/specs/2026-09-28-soundix-design.md` (approved by Scott 2026-09-28). Prototype: `docs/prototype/`.

## Decisions within the spec (not changes)

- First visit: the "Game" preset in the UI language, first event selected.
- Favorites are one global list of sound ids (spec §7 stores them apart from the set).
- A new event with a Latin name gets that name as its first search word; a Cyrillic one starts with none.
- Library audition plays at listen volume × current event volume with the event pitch spread, so what you hear is what you export.
- Own sounds are exported as they are in both formats (the browser cannot encode OGG Vorbis); the export dialog says so.
- An own sound that a link or import cannot carry becomes `{ kind: 'missing', label }` and shows "no sound"; a library id not found in the library also shows "no sound" and is skipped on export.
- Mock bindings are stored by event file name; renaming a file name updates bindings that pointed at it.
- OS junk (`__MACOSX`, `.DS_Store`, `desktop.ini`) is not copied into `packs/`; OGA packs without a licence file get a `LICENSE.txt` that states CC0 and the source page.

### Task 3: Library build script

**Files:**
- Create: `scripts/build-library.mjs`

**Interfaces:**
- Produces: `public/library/library.json` = `{ version: 1, packs: LibraryPack[], sounds: LibrarySound[] }`; files `public/library/<id>.ogg` (preview) and `<id>.<wav|mp3|flac>` (original when the source is not OGG).

Rules (spec §4.2): audio = `.ogg .wav .mp3 .flac .aif .aiff`; skip names containing `preview` (any case), anything under `__MACOSX`, names starting with `.`. If every sound of a pack sits under one top folder, drop it. `id = <pack>/<rel path without ext>` lower-cased, spaces → `-`. Tags = remaining folder names lower-cased, de-duplicated. `name` = file stem as is. Duration from ffprobe rounded to 0.01. OGG source → copied, `original = preview`. WAV/MP3/FLAC → copied original + `ffmpeg -c:a libvorbis -q:a 5` preview. AIF/AIFF → WAV with the matching little-endian PCM codec (`pcm_s24be → pcm_s24le`) + preview. Skip outputs newer than their source. Fail on duplicate ids. Run jobs in a pool of `os.cpus().length`.

- [ ] **Step 1: Write the script**

```js
// Builds public/library/ from packs/: OGG previews, export originals and library.json.
import { execFile } from 'node:child_process'
import { copyFile, mkdir, readdir, readFile, stat, writeFile } from 'node:fs/promises'
import { cpus } from 'node:os'
import { dirname, extname, join, relative, sep } from 'node:path'
import { promisify } from 'node:util'

const run = promisify(execFile)
const ROOT = join(dirname(new URL(import.meta.url).pathname.replace(/^\/(\w:)/, '$1')), '..')
const PACKS = join(ROOT, 'packs')
const OUT = join(ROOT, 'public', 'library')
const AUDIO = new Set(['.ogg', '.wav', '.mp3', '.flac', '.aif', '.aiff'])

async function walk(dir) {
  const found = []
  for (const entry of await readdir(dir, { withFileTypes: true })) {
    if (entry.name.startsWith('.') || entry.name === '__MACOSX') continue
    const full = join(dir, entry.name)
    if (entry.isDirectory()) found.push(...(await walk(full)))
    else found.push(full)
  }
  return found
}

const isSound = (file) =>
  AUDIO.has(extname(file).toLowerCase()) && !/preview/i.test(file.split(sep).pop())

/** Relative path segments; a single shared top folder is dropped. */
function segmentsOf(files, packDir) {
  const lists = files.map((f) => relative(packDir, f).split(sep))
  const top = lists[0][0]
  const shared = lists.every((s) => s.length > 1 && s[0] === top)
  return shared ? lists.map((s) => s.slice(1)) : lists
}

const slug = (text) => text.toLowerCase().replace(/ /g, '-')

async function newer(out, src) {
  try {
    return (await stat(out)).mtimeMs >= (await stat(src)).mtimeMs
  } catch {
    return false
  }
}

async function probe(file) {
  const { stdout } = await run('ffprobe', ['-v', 'error', '-show_entries',
    'format=duration:stream=codec_name', '-of', 'json', file])
  const info = JSON.parse(stdout)
  return { duration: Math.round(Number(info.format.duration) * 100) / 100, codec: info.streams[0].codec_name }
}

const ffmpeg = (args) => run('ffmpeg', ['-y', '-v', 'error', ...args])

async function buildSound(pack, file, segs) {
  const ext = extname(file).toLowerCase()
  const stem = segs.at(-1).slice(0, -extname(segs.at(-1)).length)
  const id = `${pack.id}/${[...segs.slice(0, -1), stem].map(slug).join('/')}`
  const tags = [...new Set(segs.slice(0, -1).map((s) => s.toLowerCase()))]
  const preview = `${id}.ogg`
  const { duration, codec } = await probe(file)
  let original = preview
  await mkdir(dirname(join(OUT, preview)), { recursive: true })
  if (ext === '.ogg') {
    if (!(await newer(join(OUT, preview), file))) await copyFile(file, join(OUT, preview))
  } else {
    original = ext === '.aif' || ext === '.aiff' ? `${id}.wav` : `${id}${ext}`
    const out = join(OUT, original)
    if (!(await newer(out, file))) {
      if (original.endsWith('.wav') && ext !== '.wav') {
        await ffmpeg(['-i', file, '-c:a', codec.replace(/be$/, 'le'), out])
      } else await copyFile(file, out)
    }
    if (!(await newer(join(OUT, preview), file)))
      await ffmpeg(['-i', file, '-c:a', 'libvorbis', '-q:a', '5', join(OUT, preview)])
  }
  return { id, pack: pack.id, name: stem, tags, duration, preview, original }
}

async function pool(jobs, size) {
  const results = new Array(jobs.length)
  let next = 0
  const worker = async () => {
    while (next < jobs.length) {
      const i = next++
      results[i] = await jobs[i]()
    }
  }
  await Promise.all(Array.from({ length: size }, worker))
  return results
}

async function main() {
  const packs = JSON.parse(await readFile(join(ROOT, 'packs.json'), 'utf8'))
  const jobs = []
  for (const pack of packs) {
    const dir = join(PACKS, pack.id)
    const files = (await walk(dir)).filter(isSound).sort()
    segmentsOf(files, dir).forEach((segs, i) => jobs.push(() => buildSound(pack, files[i], segs)))
  }
  const sounds = await pool(jobs, cpus().length)
  const seen = new Set()
  for (const s of sounds) {
    if (seen.has(s.id)) throw new Error(`Duplicate sound id: ${s.id}`)
    seen.add(s.id)
  }
  const library = { version: 1, packs, sounds }
  await writeFile(join(OUT, 'library.json'), JSON.stringify(library))
  for (const pack of packs) console.log(pack.id.padEnd(24), sounds.filter((s) => s.pack === pack.id).length)
  console.log('sounds:', sounds.length)
}

await main()
```

```ts
const CYRILLIC: Record<string, string> = {
  а: 'a', б: 'b', в: 'v', г: 'g', ґ: 'g', д: 'd', е: 'e', ё: 'e', є: 'ye', ж: 'zh', з: 'z',
  и: 'i', і: 'i', ї: 'yi', й: 'y', к: 'k', л: 'l', м: 'm', н: 'n', о: 'o', п: 'p', р: 'r',
  с: 's', т: 't', у: 'u', ф: 'f', х: 'kh', ц: 'ts', ч: 'ch', ш: 'sh', щ: 'shch', ъ: '',
  ы: 'y', ь: '', э: 'e', ю: 'yu', я: 'ya',
}

const MAX_LENGTH = 40

export function transliterate(text: string): string {
  return Array.from(text.toLowerCase(), (ch) => CYRILLIC[ch] ?? ch)
    .join('')
    .normalize('NFKD')
    .replace(/[\u0300-\u036f]/g, '')
}

export const isFileName = (text: string) => /^[a-z0-9_]+$/.test(text)

/** A file name of [a-z0-9_] made from any text; 'sound' when nothing is left. */
export function toFileName(text: string): string {
  const name = transliterate(text)
    .replace(/[^a-z0-9]+/g, '_')
    .replace(/^_+|_+$/g, '')
    .slice(0, MAX_LENGTH)
    .replace(/_+$/, '')
  return name || 'sound'
}

export function uniqueFileName(base: string, taken: Iterable<string>): string {
  const used = new Set(taken)
  if (!used.has(base)) return base
  let n = 2
  while (used.has(`${base}_${n}`)) n++
  return `${base}_${n}`
}
```

```ts
import type { ListSound } from './types'

export interface SearchFilter {
  query: string
  /** Pack id, '' for all packs. */
  pack: string
}

const haystack = (s: ListSound) => `${s.name} ${s.tags.join(' ')}`.toLowerCase()

/** Sounds whose name or tags contain every query word, optionally in one pack. */
export function searchSounds<T extends ListSound>(sounds: T[], { query, pack }: SearchFilter): T[] {
  const tokens = query.toLowerCase().split(/\s+/).filter(Boolean)
  return sounds.filter((s) => {
    if (pack && s.pack !== pack) return false
    const text = haystack(s)
    return tokens.every((t) => text.includes(t))
  })
}

/** Index of the first word found in the sound's name or tags, or -1. */
function rankOf(sound: ListSound, words: string[]): number {
  const name = sound.name.toLowerCase()
  const tags = sound.tags.map((t) => t.toLowerCase())
  return words.findIndex((w) => name.includes(w) || tags.some((t) => t.includes(w)))
}

/** Sounds matching the event words: an earlier word ranks higher, then a shorter sound. */
export function suggestSounds<T extends ListSound>(sounds: T[], words: string[]): T[] {
  const needles = words.map((w) => w.trim().toLowerCase()).filter(Boolean)
  return sounds
    .map((sound) => ({ sound, rank: rankOf(sound, needles) }))
    .filter((m) => m.rank >= 0)
    .sort((a, b) => a.rank - b.rank || a.sound.duration - b.sound.duration)
    .map((m) => m.sound)
}

/** Groups by pack; packs keep the order of their first sound, sounds keep their order. */
export function groupByPack<T extends ListSound>(sounds: T[]): { pack: string; sounds: T[] }[] {
  const groups = new Map<string, T[]>()
  for (const s of sounds) {
    const list = groups.get(s.pack)
    if (list) list.push(s)
    else groups.set(s.pack, [s])
  }
  return [...groups].map(([pack, list]) => ({ pack, sounds: list }))
}
```

```ts
import { toFileName, uniqueFileName } from './names'
import type { SoundEvent, SoundRef } from './types'

export const DEFAULT_VOLUME = 0.8
export const DEFAULT_PITCH = 0.05
export const MAX_PITCH = 0.2

let seq = 0
export const newKey = () => `e${Date.now().toString(36)}${(seq++).toString(36)}`

const LATIN = /^[\x20-\x7e]+$/

/** A new event; its file name is the unique transliteration of the name. */
export function createEvent(name: string, events: SoundEvent[]): SoundEvent {
  const title = name.trim()
  const file = uniqueFileName(toFileName(title), events.map((e) => e.file))
  return {
    key: newKey(),
    name: title || file,
    file,
    sound: null,
    volume: DEFAULT_VOLUME,
    pitch: DEFAULT_PITCH,
    words: LATIN.test(title) ? [title.toLowerCase()] : [],
  }
}

/** Cleans a file name typed for one event and keeps it unique in the set. */
export function fixFileName(raw: string, key: string, events: SoundEvent[]): string {
  const others = events.filter((e) => e.key !== key).map((e) => e.file)
  return uniqueFileName(toFileName(raw), others)
}

export interface RawEvent {
  name?: unknown
  file?: unknown
  volume?: unknown
  pitch?: unknown
  words?: unknown
  sound: SoundRef | null
}

const clamp = (value: unknown, max: number, fallback: number) =>
  typeof value === 'number' && Number.isFinite(value) ? Math.min(max, Math.max(0, value)) : fallback

const text = (value: unknown) => (typeof value === 'string' ? value.trim() : '')

/** Valid events from untrusted input: unique file names, clamped numbers, string words. */
export function sanitizeEvents(raw: RawEvent[]): SoundEvent[] {
  const events: SoundEvent[] = []
  for (const r of raw) {
    const name = text(r.name) || text(r.file)
    const file = uniqueFileName(toFileName(text(r.file) || name), events.map((e) => e.file))
    events.push({
      key: newKey(),
      name: name || file,
      file,
      sound: r.sound,
      volume: clamp(r.volume, 1, DEFAULT_VOLUME),
      pitch: clamp(r.pitch, MAX_PITCH, DEFAULT_PITCH),
      words: Array.isArray(r.words) ? r.words.filter((w): w is string => typeof w === 'string') : [],
    })
  }
  return events
}
```

```ts
import { isFileName } from './names'
import { MOCK_KEYS, type MockBindings, type MockKey, type SoundEvent } from './types'

export const MOCK_DEFAULTS: Record<MockKey, string> = {
  hover: 'hover', click: 'click', toggle: 'toggle', tab: 'tab', slider: 'click', open: 'open',
  close: 'close', notify: 'notify', purchase: 'purchase', reward: 'reward', locked: 'locked',
}

export type Binding =
  | { state: 'event'; event: SoundEvent }
  | { state: 'silent' }
  /** The bound file name is not in the set. */
  | { state: 'missing'; file: string }

export const bindingFile = (key: MockKey, bindings: MockBindings): string | null =>
  bindings[key] !== undefined ? (bindings[key] as string | null) : MOCK_DEFAULTS[key]

export function resolveBinding(key: MockKey, bindings: MockBindings, events: SoundEvent[]): Binding {
  const file = bindingFile(key, bindings)
  if (file === null) return { state: 'silent' }
  const event = events.find((e) => e.file === file)
  return event ? { state: 'event', event } : { state: 'missing', file }
}

/** Elements that played the old file name keep playing the renamed event. */
export function renameInBindings(bindings: MockBindings, from: string, to: string): MockBindings {
  const next = { ...bindings }
  for (const key of MOCK_KEYS) if (bindingFile(key, bindings) === from) next[key] = to
  return next
}

export function sanitizeBindings(raw: unknown): MockBindings {
  const out: MockBindings = {}
  if (!raw || typeof raw !== 'object') return out
  for (const key of MOCK_KEYS) {
    const value = (raw as Record<string, unknown>)[key]
    if (value === null || (typeof value === 'string' && isFileName(value))) out[key] = value
  }
  return out
}
```

```ts
import { compressToEncodedURIComponent, decompressFromEncodedURIComponent } from 'lz-string'
import { sanitizeBindings } from './mock'
import { sanitizeEvents } from './set'
import type { MockBindings, SoundEvent, SoundRef } from './types'

export const SHARE_VERSION = 1

export interface ShareData {
  events: SoundEvent[]
  bindings: MockBindings
}

type SharedSound = string | { own: string } | null

function packSound(ref: SoundRef | null): SharedSound {
  if (!ref) return null
  if (ref.kind === 'library') return ref.id
  return { own: ref.kind === 'own' ? ref.name : ref.label }
}

function unpackSound(value: unknown): SoundRef | null {
  if (typeof value === 'string' && value) return { kind: 'library', id: value }
  const own = (value as { own?: unknown } | null)?.own
  return typeof own === 'string' ? { kind: 'missing', label: own } : null
}

export function encodeShare({ events, bindings }: ShareData): string {
  const payload = {
    soundix: SHARE_VERSION,
    events: events.map((e) => ({
      name: e.name, file: e.file, sound: packSound(e.sound), volume: e.volume, pitch: e.pitch, words: e.words,
    })),
    mock: bindings,
  }
  return compressToEncodedURIComponent(JSON.stringify(payload))
}

export function decodeShare(text: string): ShareData | null {
  try {
    const payload = JSON.parse(decompressFromEncodedURIComponent(text) || '')
    if (payload?.soundix !== SHARE_VERSION || !Array.isArray(payload.events)) return null
    const raw = payload.events.filter((e: unknown) => e && typeof e === 'object')
    return {
      events: sanitizeEvents(raw.map((e: Record<string, unknown>) => ({ ...e, sound: unpackSound(e.sound) }))),
      bindings: sanitizeBindings(payload.mock),
    }
  } catch {
    return null
  }
}

export const shareUrl = (base: string, data: ShareData) => `${base}#s=${encodeShare(data)}`

export const readShareHash = (hash: string) => (hash.startsWith('#s=') ? hash.slice(3) : null)
```

```ts
import type { SoundixSource } from './soundix-json'
import type { Library, LibraryPack, SoundEvent } from './types'

export type ExportFormat = 'original' | 'ogg'

export interface ExportEntry {
  event: SoundEvent
  /** Path inside the archive, e.g. sounds/click.ogg */
  path: string
  /** A library file (path under library/) or an own sound id. */
  body: { url: string } | { own: string }
  source: SoundixSource
  pack?: LibraryPack
}

export const extOf = (path: string) => /\.([a-z0-9]+)$/i.exec(path)?.[1].toLowerCase() ?? ''

/** The archive file of every event that has a sound; the rest are skipped. */
export function resolveEntries(events: SoundEvent[], library: Library, format: ExportFormat) {
  const sounds = new Map(library.sounds.map((s) => [s.id, s]))
  const packs = new Map(library.packs.map((p) => [p.id, p]))
  const entries: ExportEntry[] = []
  const skipped: SoundEvent[] = []
  for (const event of events) {
    const ref = event.sound
    const sound = ref?.kind === 'library' ? sounds.get(ref.id) : undefined
    const pack = sound && packs.get(sound.pack)
    if (sound && pack) {
      const url = format === 'ogg' ? sound.preview : sound.original
      entries.push({
        event, pack, path: `sounds/${event.file}.${extOf(url)}`, body: { url },
        source: { library: sound.id, pack: pack.name, author: pack.author, license: pack.license, url: pack.url },
      })
    } else if (ref?.kind === 'own') {
      entries.push({
        event, path: `sounds/${event.file}.${extOf(ref.name) || 'audio'}`, body: { own: ref.id },
        source: { own: true, original: ref.name },
      })
    } else skipped.push(event)
  }
  return { entries, skipped }
}
```

`src/core/soundix-json.ts`:
```ts
import type { ExportEntry } from './entries'
import { sanitizeEvents } from './set'
import type { SoundEvent, SoundRef } from './types'

export interface SoundixSource {
  library?: string
  pack?: string
  author?: string
  license?: string
  url?: string
  own?: true
  original?: string
}

export interface SoundixJson {
  soundix: 1
  events: {
    id: string
    name: string
    file: string
    volume: number
    pitch: number
    words: string[]
    source: SoundixSource
  }[]
}

const round = (n: number, digits: number) => Math.round(n * 10 ** digits) / 10 ** digits

export function buildSoundixJson(entries: ExportEntry[]): SoundixJson {
  return {
    soundix: 1,
    events: entries.map(({ event, path, source }) => ({
      id: event.file, name: event.name, file: path,
      volume: round(event.volume, 2), pitch: round(event.pitch, 3), words: event.words, source,
    })),
  }
}

export type ImportError = 'not-json' | 'not-soundix' | 'bad-version' | 'bad-events'
export type ImportResult = { ok: true; events: SoundEvent[] } | { ok: false; error: ImportError }

type Obj = Record<string, unknown>
const isObj = (v: unknown): v is Obj => !!v && typeof v === 'object' && !Array.isArray(v)
const fail = (error: ImportError): ImportResult => ({ ok: false, error })

function refOf(source: unknown): SoundRef | null {
  if (!isObj(source)) return null
  if (typeof source.library === 'string') return { kind: 'library', id: source.library }
  if (source.own === true) return { kind: 'missing', label: String(source.original ?? '') }
  return null
}

export function parseSoundixJson(text: string): ImportResult {
  let data: unknown
  try {
    data = JSON.parse(text)
  } catch {
    return fail('not-json')
  }
  if (!isObj(data) || !('soundix' in data)) return fail('not-soundix')
  if (data.soundix !== 1) return fail('bad-version')
  const list = data.events
  if (!Array.isArray(list) || !list.every((e) => isObj(e) && typeof e.id === 'string')) return fail('bad-events')
  const events = sanitizeEvents(
    (list as Obj[]).map((e) => ({ name: e.name, file: e.id, volume: e.volume, pitch: e.pitch, words: e.words, sound: refOf(e.source) })),
  )
  return { ok: true, events }
}
```
